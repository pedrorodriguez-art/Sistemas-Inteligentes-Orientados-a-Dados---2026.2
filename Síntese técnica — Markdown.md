## 6. Síntese técnica

Os dados necessários para começar o projeto estão disponíveis, mas ainda não estão completos para realizar a análise de acesso como planejada. Já foi possível obter as UPAs pelo CNES, os dados de população por bairro pelo IBGE e uma primeira base de pontos de ônibus pelo OpenStreetMap, utilizando o Overpass Turbo. O principal ponto que ainda falta é conseguir relacionar a localização das UPAs e da população com as opções de transporte e seus trajetos por meio de uma API de mapas. Essa integração é importante para sair de uma análise baseada apenas em distância e chegar a uma estimativa mais próxima do acesso real.

O principal problema encontrado até o momento está justamente nos dados de transporte. O Overpass Turbo permitiu coletar os pontos de ônibus, mas as informações disponíveis não são suficientes para analisar todas as opções de deslocamento até as UPAs, principalmente em relação às linhas e aos trajetos. Por isso, a maior dificuldade atual do projeto é substituir ou complementar essa base por dados obtidos através do Google Maps, além de validar o formato das coordenadas de localização fornecidas pelo CNES antes de utilizá-las na API.

Não considero que exista, neste momento, uma informação que seja impossível de obter. O que ainda não está definido é a melhor forma de acessar e coletar os dados de transporte necessários, principalmente as informações sobre linhas, trajetos e opções de deslocamento. A próxima etapa será justamente verificar o que a API do Google Maps permite consultar e como esses dados podem ser integrados às informações do CNES e do IBGE.

A caracterização dos dados fez com que o escopo do projeto ficasse mais claro. A pergunta inicial “Quão fácil ou difícil é para a população de cada região de Salvador chegar a uma UPA?” passa a ser representada pela pergunta central: “Quais regiões de Salvador apresentam maior dificuldade de acesso às UPAs, considerando população, localização dos serviços e disponibilidade de transporte público?”. A hipótese continua sendo que “A acessibilidade às UPAs apresenta desigualdades territoriais que não podem ser explicadas apenas pela distância geográfica, sendo influenciada também pela disponibilidade e pelas características do transporte público”. Portanto, não houve uma mudança na ideia principal, mas houve um refinamento do que será considerado como acesso.

Neste momento, o principal risco do projeto está na obtenção dos dados de transporte. Se a mudança do Overpass para uma fonte como o Google Maps não fornecer informações suficientes ou tiver limitações de acesso, a análise poderá ficar restrita à distância geográfica e à localização dos pontos de ônibus. Isso diminuiria a capacidade de testar a hipótese de que o transporte público influencia a acessibilidade às UPAs, que é justamente uma das partes mais importantes do projeto.
